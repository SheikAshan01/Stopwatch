# ⏱️ Stopwatch

A simple, responsive, and user-friendly stopwatch web application
built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

🚀 **[Try the Stopwatch](https://stopwatch-nine-lyart.vercel.app/)**

## ✨ Features

- ⏱️ Start stopwatch
- ⏸️ Pause stopwatch
- 🔄 Reset stopwatch
- 🕐 Real-time time tracking
- 📱 Responsive design
- 🎨 Clean and simple interface
- ⚡ Lightweight frontend application

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
